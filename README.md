# CH32V407 Arduino – Boards Manager files

Add this URL in Arduino IDE → File → Preferences → Additional boards manager URLs:

https://raw.githubusercontent.com/medtty/board_manager_files/main/package_ch32v407_index.json

Then Tools → Board → Boards Manager → search "CH32V407" → Install.

Core source: https://github.com/medtty/arduino_core_ch32v407
Toolchain archives (WCH GCC 15, WCH OpenOCD from MounRiver Studio) are attached to this repository's Releases.
